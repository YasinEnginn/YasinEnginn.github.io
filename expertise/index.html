Shared Method

What stays constant across the three tracks

  1. Make the system rebuildableTopologies, dependencies, configurations, and run steps should be explicit.
  2. Separate intent from mechanismThe desired outcome should not disappear inside transport-specific commands.
  3. Treat failure as behaviorTimeouts, partitions, invalid state, and recovery paths belong in the design.
  4. Validate with evidenceLogs, queries, metrics, packet behavior, and test output make claims reviewable.
  5. Explain the boundaryFinished work, reproduced work, current learning, and future plans should remain distinguishable.
